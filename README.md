## 🚀 Projetos em Destaque

* 📅 **[Agenda Fácil](https://github.com/Guims0/AgendaFacil):** API REST de agendamentos desenvolvida em **Java e Spring Boot**. Apresenta regras de negócio complexas como travas anti-overbooking, validação de expediente, controle de acessos modular (**Spring Security + JWT**) e carteira digital com divisões automatizadas de pagamentos. Projeto validado por testes unitários com **JUnit 5 e Mockito** e documentado via **Swagger**.
* ⛅ **[Clima API](https://github.com/Guims0/api_clima):** API desenvolvida com **Java e Spring Boot** que consome serviços externos (OpenWeather e GeoIP), processa previsão do tempo, aplica tratamento global de exceções e mantém histórico no **MySQL**.
* 🏬 **[Sistema de Gestão de Loja](https://github.com/Guims0/SistemaGestaoLoja):** Aplicação para gerenciamento comercial, focada no controle de estoque e fluxos essenciais de venda.
